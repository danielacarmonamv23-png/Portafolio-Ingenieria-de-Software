Sobre el proyecto

Esta calculadora permite realizar operaciones matemáticas básicas. El proyecto utiliza HTML para la estructura, CSS para el diseño y JavaScript para la lógica y la interacción con los botones.

HTML

Organiza la estructura, los textos y los botones de la página.

CSS

Define la apariencia, distribución y adaptación a diferentes pantallas.

JavaScript

Controla las operaciones y los eventos realizados por el usuario.
