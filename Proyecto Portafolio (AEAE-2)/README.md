# Mi Portafolio Web Interactivo

## Descripción

Este proyecto consiste en el desarrollo de un portafolio web personal realizado como actividad integradora de la Unidad 1.

El proyecto integra HTML5, CSS3 y JavaScript para demostrar conocimientos de estructura semántica, diseño responsivo, manipulación del DOM y programación de interactividad en el navegador.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## Características

- Presentación personal.
- Sección "Sobre mí".
- Tres proyectos.
- Carga dinámica de proyectos mediante JavaScript.
- Formulario de contacto.
- Validación del formulario.
- Menú responsive.
- Diseño adaptable a dispositivos móviles, tablets y computadores.
- Cambio entre tema claro y oscuro.
- Animaciones y transiciones.

## Instalación y ejecución

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir `index.html` en un navegador.
4. También se puede utilizar Live Server en Visual Studio Code.
