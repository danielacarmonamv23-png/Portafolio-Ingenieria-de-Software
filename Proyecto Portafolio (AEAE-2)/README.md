# Mi Portafolio Web


## Estructura del proyecto

- `index.html`: página principal.
- `css/`: archivos de estilos.
- `js/`: archivos JavaScript.
- `assets/`: imágenes e iconos.
- `documentacion/`: documentación del proyecto.

## Proyectos

Los proyectos se encuentran en un arreglo dentro de `js/main.js` y se muestran
automáticamente en la página mediante JavaScript.

## Formulario

El formulario utiliza validación HTML5 y JavaScript para simular el envío del mensaje.
