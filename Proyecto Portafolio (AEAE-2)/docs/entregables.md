# Entregables de la actividad

## 1. Requerimientos funcionales

1. Mostrar una sección de presentación personal.
2. Mostrar mínimo tres proyectos.
3. Cargar proyectos dinámicamente mediante JavaScript.
4. Incluir un formulario de contacto.
5. Validar los datos del formulario.
6. Incluir menú de navegación responsive.
7. Incluir menú hamburguesa en móvil.
8. Permitir cambiar entre tema claro y oscuro.

## 2. Requerimientos no funcionales

1. Diseño responsive para móvil, tablet y escritorio.
2. Uso de HTML5 semántico.
3. Uso de CSS3.
4. Uso de JavaScript vanilla.
5. Código organizado por responsabilidades.
6. Accesibilidad básica mediante atributos alt y labels.
7. Código mantenible mediante variables CSS.
8. Despliegue mediante GitHub Pages.

## 6. Autoevaluación

### ¿Qué fue lo más difícil?

Lo más difícil fue implementar JavaScript, especialmente la manipulación del DOM y la carga dinámica de los proyectos. Fue necesario comprender cómo almacenar información en un arreglo de objetos y recorrerlo para crear las tarjetas.

### ¿Cómo se relaciona la arquitectura con la programación estructurada?

La arquitectura se relaciona con la programación estructurada porque las funcionalidades están organizadas en diferentes archivos y funciones. HTML maneja la estructura, CSS la presentación y JavaScript el comportamiento. Se utilizan variables, funciones, condicionales, ciclos y eventos.

### ¿Qué mejoraría con más tiempo?

Mejoraría el diseño visual, agregaría más proyectos y optimizaría las animaciones. También implementaría un formulario conectado a un servicio real, filtros de proyectos y más opciones de accesibilidad.
